# benevol.app status

Public status page of [benevol.app](https://www.benevol.app), at https://statut.benevol.app.

Built with [Upptime](https://upptime.js.org): GitHub Actions check the public URLs every 5 minutes from outside the production server, open an issue in this repository when one is down, and close it when it is back. Configuration in `.upptimerc.yml`.
